# Learning Playwright

This repository contains code examples and tests for the LinkedIn Learning course "Learning Playwright".

## Prerequisites

- Node.js
- npm

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

## Running Tests

To run all tests:

```bash
npm test
```

To run tests in a specific browser:

```bash
npm run test:chromium
```

To run tests locally (assuming a local server):

```bash
npm run test:local
```

To view the test report:

```bash
npm run test:report
```

To run tests with UI mode:

```bash
npm run test:ui
```
